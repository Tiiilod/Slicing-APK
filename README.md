# 💄 Beauty Shop Mobile App

Aplikasi mobile e-commerce untuk penjualan produk kecantikan dan kosmetik. Aplikasi ini menampilkan katalog produk dengan desain sederhana, modern, dan responsif sehingga memudahkan pengguna dalam mencari serta membeli produk kecantikan.

## ✨ Fitur

- 🔍 Pencarian produk melalui search bar
- 📷 Scan produk menggunakan kamera
- 🛒 Keranjang belanja (Shopping Cart)
- 💬 Fitur pesan/chat
- 🏷️ Label promo dan diskon produk
- ⭐ Rating produk
- 💰 Tampilan harga yang jelas
- 📦 Daftar produk dalam bentuk grid
- 🎨 UI modern dengan tema warna oranye
